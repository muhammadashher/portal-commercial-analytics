# Portal Commercial Analytics: Property & Jobs Inside Sales

An end-to-end commercial analytics project for a UAE online classifieds portal with two verticals, **Property** (real estate agencies buying listing packages) and **Jobs** (employers buying job-posting packages). It covers the work a commercial analyst does every week: target setting, performance tracking, sales productivity, churn and upsell analysis, P&L monitoring and competitor pricing.

> **Data note:** all data is synthetic, generated by `src/generate_data.py` to behave like a real portal (Dubai areas, UAE seasonality, package tiers, rep-level sales activity). Competitor prices are illustrative. No real company data is used.

## Business questions

1. Are current sales targets fair and realistic, and how should Q4 2026 targets be set?
2. Which reps and funnel stages drive new business, and where is productivity lost?
3. Which accounts are likely to churn next, and how much revenue is at risk?
4. Do discounts actually buy retention, and where are the upsell opportunities?
5. What is each vertical's P&L and contribution margin?
6. How does our cost per lead compare with competitors?

## Key results

| Area | Result |
|---|---|
| Scale | 24 months, 1,411 accounts, 18 inside-sales reps, 19K+ account-month records, AED 43M revenue in the last 12 months |
| Target setting | Bottom-up capacity model cut target error (MAPE) from **33.4% to 8.9%** in a Q3 2026 backtest; reps within ±10% of target rose from **39% to 72%**; attainment spread narrowed from 43–147% to 86–104% |
| Sales productivity | Top-quartile reps convert **11.6%** of meetings to deals vs **5.2%** for the bottom quartile (Property) |
| Churn risk | Out-of-time logistic regression (AUC 0.65); weekly watchlist of **87 accounts worth AED 114K/month** |
| Discounts | 15%+ discounts lowered Property churn by only 0.3 points a month yet cost **AED 3.8M** in 12 months |
| Upsell | **11 accounts** at 85%+ package usage for 3 months: **AED 30K/month** upgrade potential |
| P&L | 12-month contribution margin: Property **61.4%**, Jobs **54.1%** |
| Pricing | Competitors' cost per lead is 6–52% higher than ours across package tiers |

## Methods

**Target setting.** The legacy method takes last quarter's vertical revenue × 1.12 and splits it equally across reps, which ignores each rep's book size and churn. The bottom-up model projects each rep's month-*k* revenue as

`book × (1 − churn)^k + new-business run-rate × Σ (1 − churn)^(k − j)`

using trailing-6-month churn and new-business run-rate, then scales every rep's figure so the vertical total equals the company goal. Both methods are backtested on Q3 2026 using only data available up to June 2026.

**Churn model.** Logistic regression on account-month features (utilization, leads or applications per unit vs market median, 3-month engagement trend, discount, tenure, package tier, segment). Trained on Oct 2024 – Mar 2026 and tested on Apr – Sep 2026 so the evaluation is out of time.

**P&L.** Net revenue less payment fees, platform cost allocation, sales-team cost, commissions and marketing spend, giving monthly contribution and margin by vertical.

**Pricing.** Cost per lead = monthly package price ÷ (listing credits × utilization × leads per listing × lead-quality index).

## SQL highlights

- `01_monthly_kpis.sql`: revenue, ARPA, logo churn and YoY growth with `LAG() OVER` a named window
- `02_target_attainment.sql`: attainment, `RANK()` within vertical and 3-month rolling average
- `03_sales_funnel.sql`: calls → meetings → deals funnel with `NTILE(4)` productivity quartiles
- `04_net_revenue_retention.sql`: 12-month NRR and GRR from a self-join on month offsets
- `05_upsell_opportunities.sql`: `ROW_NUMBER()` to find 3 consecutive high-usage months
- `06_discount_effectiveness.sql`: churn and revenue given away by discount band

## Excel model

`outputs/Q4_2026_Target_Model.xlsx` is a live model: change the growth goal (yellow cell) or any rep input and every target updates. Sheets: Read Me, Assumptions, Rep Targets, Q3 Backtest, P&L, Pricing. Blue = inputs, black = formulas, green = links to other sheets.

```bash

python pipeline.py          # generate data, build DB, run analysis, build Excel model
pytest -q                   # 6 tests
streamlit run app.py        # open the dashboard
```
